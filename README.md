# 织星 · Star Weaver

以星光为线，一笔连起整片夜空。四季 32 个星座的一笔画解谜，手机和电脑都能玩。

- **春 · 初织**：一笔连完所有星线，每条只走一次
- **夏 · 鹊桥**：双线要来回走两次
- **秋 · 流星**：带箭头的线只能顺着方向走
- **冬 · 星门**：走进星门，会从同色的另一扇出来

## 本地运行

```
python serve.py
```

然后打开 http://localhost:8777 。纯 HTML/JS，无需构建。网址加 `?all` 可解锁全部关卡（调试用）。

## 文件

| 文件 | 内容 |
|---|---|
| `js/levels.js` | 四季关卡数据（坐标 0~100，边 `a-b` / `a=b` 鹊桥 / `a>b` 流星，`portals` 星门） |
| `js/solver.js` | 关卡解析与求解（游戏内提示、校验脚本共用） |
| `js/board.js` | 星与星线的绘制、拖拽连线、撤销 / 提示 / 胜利动画 |
| `js/sky.js` | 夜空背景：银河、山丘、流星、季节粒子 |
| `js/audio.js` | 合成钢琴与钟琴：每画一笔奏出旋律的下一个音，季节氛围配乐 |
| `js/main.js` | 界面流程、存档（localStorage）、主循环 |
| `tools/verify.js` | 关卡校验 |

## 改关卡

改完 `js/levels.js` 后运行：

```
node tools/verify.js
```

会检查每关是否有解、星距是否够大、星线是否擦过别的星，并给出"随机成功率"（随便乱连能通关的比例，越低越难），用来排难度曲线。
